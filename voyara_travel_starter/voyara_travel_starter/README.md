# Voyara starter prototype

This folder contains the original static HTML concept and remains available as a fallback when the React build is absent.

The maintained, component-based application now lives in [`travel-app/frontend`](../../travel-app/frontend/). Its FastAPI backend, database schema, auth, catalog, booking, itinerary and assistant APIs are in [`travel-app/backend`](../../travel-app/backend/). Follow [`travel-app/README.md`](../../travel-app/README.md) to run the integrated platform.
