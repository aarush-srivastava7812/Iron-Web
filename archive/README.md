# Recoverable historical material

`2026-10-12/` preserves the project state and material retired during the verified cleanup.

- `legacy-code/`: earlier phase runners, duplicated evaluation frameworks, graph repair scripts, diagnostics and the former MCP-labelled facade.
- `design-history/`: prior plans, phase documentation, dependency declarations and acquisition code.
- `reports/`: historical generated write-ups.
- `external-checkouts/`: unused Letta source and unrelated benchmark checkout material. These local trees are excluded from Git commits.
- `run-records/` and `data/`: historical outputs and experiment stores. These local trees are excluded from Git commits.
- `review-evidence/` and `maintenance-scripts/`: dated inspection and implementation scripts, when present.

The archived code and reports describe earlier behavior and metric definitions. They are not current entry points or current performance claims.

`source_moves.json` and `script_moves.json` record file checksums at relocation. Research and test files intentionally edited after relocation also have their history in Git. `state_manifest.json` records archived tree fingerprints and unchanged retained input groups. Reverse a recorded move to restore a group to its original path; inspect conflicts before replacing existing files. Original source is also available with `git show 724c551:<path>`.

The active credentials, memory stores, original benchmark records, provenance, required evaluator references, genuine extraction/model caches and research papers were retained separately.
