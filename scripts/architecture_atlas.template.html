Two kinds of memory stay separate

Confirmed traveler preferences retain user authority. TinyFish observations are stored with origin=tool, user_confirmed=false and instruction_authority=false.

No web observation becomes a confirmed Traveller claim. “Fresh” means recently retrieved; it does not establish truth or trip-date applicability.

Agent output needs a separate evidence-ingestion bridge.
