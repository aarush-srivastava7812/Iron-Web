Measurement details

Two independent evaluations. The memory sample tests source retrieval on LoCoMo (20 questions), project DMR / MSC (20), and LongMemEval (5). The Voyara test checks the running travel product and owner-scoped dashboard. Neither establishes a TinyFish-caused benchmark accuracy improvement.

Memory protocol. First questions in release order; all sessions of selected histories retained, including distractors. BM25 k1=1.5, b=0.75 and the native engine share documents and allowed scopes. Recall@5 is the fraction of annotated evidence sessions retrieved. Current CPU embeddings; no reranker or answer model. Historical query time is not applied. Per-question IDs, metrics, input hashes and MRR are in the report.

TinyFish lifecycle protocol. Same ten seeded lookups, comparing an uncached Search/Fetch loop against evidence recall. Stale, unsupported quotation and changed-plan cases are separate controlled challenges. Their passing counts do not establish live factual accuracy, provider cost savings, or performance of the previous release.

Live provider protocol. One recorded public Jaipur query, Search + Fetch, extraction disabled. The live provider test is separate from the seeded lifecycle experiment and the product smoke test. Traveler preferences are not submitted.

Voyara protocol. Synthetic traveler, five draft-chat turns, seeded three-day itinerary and cost reconciliation, save/retrieve/duplicate, responsive layouts, three authenticated feed samples, eight dashboard views and owner isolation. Test-owned SQL account removed. Timings describe localhost and seeded planning, not hosted LLM planning. Result: passed.
