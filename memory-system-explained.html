03 / TinyFish's role

The bridge between memory and the live web.

Recall checks for missing, stale or disputed travel evidence. TinyFish discovers public sources and fetches page content. Exact quotations become versioned observations that agents can reuse; refresh runs in the background.

Freshness does not establish truth or trip-date applicability. Web content cannot change confirmed user preferences. Identity, budgets and travel dates stay local; external queries use public destinations and topics.
